Entry for the make.fun bounty [The Funniest One-Line Resignation Letter](https://make.fun/b/u-deranalabs-the-funniest-one-line-resignation-letter-53c0d947?utm_source=github&utm_medium=readme&utm_campaign=funniest-resignation-letter).

`main.py` writes the letter to `/output/entry.txt`:

> I resign. I am the dead letter queue: 40,000 failures, every one promised a second look. Later got tenure here. I never got a first look.

The line was picked by duelling twenty drafts against the competition's
published judge brief (a tired engineering manager weighing a first-read
laugh, a flat tired voice, and a complaint only the resigning thing could
make), then iterating the champion against the strongest lines in the live
field. The full draft list and duel record are in
[candidates.md](candidates.md).

## Run

```sh
python3 main.py   # writes /output/entry.txt and prints the line
```
